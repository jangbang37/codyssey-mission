# 🚀 Codyssey Mission: 과제 종합 보고서

- 공용 PC 환경이라 도커 프로그램을 직접 깔지 못했지만, GitHub 웹사이트를 통해 과제 파일을 안전하게 모두 올렸습니다!
- 아래는 과제에서 요구하는 멋진 내용들을 정리한 기록입니다.

## 1. 파일 소개
- `index.html`: "Hello, Codyssey!" 웹페이지 파일
- `Dockerfile`: Nginx 웹서버 설정 파일
- `README.md`: 과제 설명서 및 보고서

## 2. 도커와 웹서버 공부 내용
- **이미지와 컨테이너:** 이미지는 레고 설명서이고, 컨테이너는 그 설명서대로 만든 멋진 장난감이에요!
- **Nginx:** 우리가 만든 예쁜 웹페이지를 인터넷 세상에 뿅 하고 보여주는 고마운 친구랍니다.
- **포트포워딩:** 컴퓨터 안팎으로 문을 연결해 줘서 웹페이지를 볼 수 있게 해주는 마법의 통로예요.
