## 📌 1. 프로젝트 개요 및 디렉토리 구조
본 프로젝트는 제한된 공용 PC 환경에서 GitHub 웹 인터페이스(Web UI)를 활용하여 웹서버(`Nginx`)를 구동하기 위한 파일들을 구성하고, 도커 및 리눅스 시스템 운영에 필요한 핵심 개념과 검증 절차를 문서화한 과제입니다.
